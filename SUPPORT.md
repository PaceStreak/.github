# Support

## Something is broken

1. Check **[status.pacestreak.com](https://status.pacestreak.com)** first. If a
   service is already down, what you are seeing is probably a symptom of that.
2. Search the existing issues in the repository it belongs to
   ([`app`](https://github.com/PaceStreak/app/issues) for the product,
   [`web`](https://github.com/PaceStreak/web/issues) for the public site). It
   may already be known.
3. Open a bug report with the steps to reproduce.

## I have a question about the product

Email **<hello@pacestreak.com>**, read by a person. How something works, why it
works that way, or what you'd like it to do: all fine to ask there. The
[FAQ](https://www.pacestreak.com/faq) answers the common ones.

## I lost something I deleted

Deleted habits, sessions, meals, recipes and journal entries wait in the trash
for 30 days: **Settings → Data → Open the trash** in the app.

## I found a security problem

**Do not open an issue.** Email **<hello@pacestreak.com>**. See
[SECURITY.md](./SECURITY.md).

## I want to contribute

See [CONTRIBUTING.md](./CONTRIBUTING.md). Open an issue before writing anything
non-trivial: a pull request can be declined on scope rather than quality, and a
short issue first saves you that.

## What is not supported

PaceStreak is built by one person. There is no support SLA, no
guaranteed response time beyond the 72 hours promised for security reports, and
no phone or chat support. What you will get is a straight answer.
